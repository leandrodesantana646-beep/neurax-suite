# 🚀 NeuraX Suite | IA & Negócios

> Plataforma SaaS completa e inteligente de automação para negócios, desenvolvida para otimizar a precificação de produtos, gerar copies de alta conversão, planejar conteúdos e estruturar estratégias empresariais utilizando Inteligência Artificial.

---

## 📸 Sobre o Projeto

O **NeuraX Suite** foi construído do zero com foco em produtividade para empreendedores, donos de e-commerce e criadores de conteúdo. A aplicação combina uma interface moderna e responsiva com modelos avançados de Inteligência Artificial para entregar relatórios e conteúdos estratégicos em segundos.

---

## ✨ Principais Funcionalidades

- 💰 **Precificação Inteligente por IA:** Analisa o custo de produção de um produto, estima o preço médio de mercado atual e calcula automaticamente a margem ideal para garantir **100% de lucro**.
- 💬 **Gerador de Copy para WhatsApp:** Cria abordagens comerciais e scripts de vendas persuasivos e personalizados para o seu produto.
- 📸 **Planejador de Conteúdo para Instagram:** Desenvolve estruturas completas de posts em carrossel e legendas magnéticas para engajar o público.
- 🎯 **Consultor Estratégico de Negócios:** Gera planos de ação detalhados baseados nos objetivos principais da empresa.
- 🔐 **Sistema de Autenticação:** Controle de acesso por usuário com painel de controle interativo.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias modernas de desenvolvimento web e inteligência artificial:

* **Python** (Linguagem principal)
* **Streamlit** (Framework para construção da interface web e deploy em nuvem)
* **Groq API / Llama 3.3** (Motor de Inteligência Artificial de alta performance)
* **Cloud Computing** (Hospedagem contínua via Streamlit Cloud)
